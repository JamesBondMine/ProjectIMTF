重要提示：在使用趣聊（以下简称"我们"或"本应用"）之前，请您务必认真阅读并充分理解本《隐私政策》。 一旦您开始使用我们的产品或服务，即表示您已充分理解并同意本政策的全部内容。

一、我们如何收集和使用您的个人信息

1.1 账号注册与登录

当您注册或登录趣聊账号时，我们会收集以下信息：

  • 手机号码：用于创建账号、登录验证和账号安全保护
  • 密码：用于账号登录验证（加密存储）
  • 昵称：用于个人资料展示
  • 头像：用于个人资料展示（可选）

1.2 社交功能

为了向您提供社交服务，我们需要收集和使用以下信息：

  • 聊天消息：包括文字、图片、语音、视频等消息内容
  • 好友关系：您添加的好友列表和好友信息
  • 动态内容：您发布的动态、评论、点赞等互动信息
  • 群组信息：您创建或加入的群组及相关消息

1.3 设备信息

为了保障服务的正常运行和账号安全，我们会收集以下设备信息：

  • 设备型号：用于适配不同设备
  • 操作系统版本：用于兼容性优化
  • 网络类型：用于网络优化
  • IP地址：用于安全防护和地域服务
  • 设备标识符：用于设备管理和安全验证

1.4 权限使用

为了实现特定功能，我们可能需要您授权以下权限：

  • 相机权限：用于拍摄照片/视频并发送消息
  • 相册权限：用于选择照片/视频并发送消息
  • 麦克风权限：用于录制和发送语音消息
  • 存储权限：用于保存图片、视频等文件
  • 通知权限：用于接收消息通知

您可以在设备的设置中随时关闭这些权限，但可能会影响相关功能的使用。

二、我们如何使用 Cookie 和同类技术

为确保服务正常运行，我们会在您的设备上存储Cookie和本地存储数据，这些技术帮助我们：

  • 保持您的登录状态
  • 记住您的偏好设置
  • 分析服务使用情况
  • 提升服务性能

您可以通过应用设置来管理或清除这些数据。

三、我们如何共享、转让、公开披露您的个人信息

3.1 共享

我们不会与任何第三方公司、组织和个人分享您的个人信息，但以下情况除外：

  • 获得您的明确同意：在获得您的明确同意后，我们会与第三方共享您的个人信息
  • 法律法规要求：根据法律法规、诉讼争议解决需要，或按行政、司法机关依法提出的要求
  • 第三方服务提供商：为了提供服务，我们可能会使用第三方服务（如云存储、推送服务等），这些服务提供商会严格遵守保密义务

3.2 转让

我们不会将您的个人信息转让给任何公司、组织和个人，但以下情况除外：

  • 在获取明确同意的情况下转让
  • 在涉及合并、收购或破产清算时，如涉及到个人信息转让，我们会要求新的持有您个人信息的公司、组织继续受此隐私政策的约束

3.3 公开披露

我们仅会在以下情况下，公开披露您的个人信息：

  • 获得您的明确同意
  • 基于法律的披露：在法律、法律程序、诉讼或政府主管部门强制性要求的情况下

四、我们如何保护您的个人信息

我们非常重视您的个人信息安全，并采取了业界标准的安全措施来保护您的信息：

4.1 技术措施

  • 数据加密：我们使用加密技术对您的个人信息进行加密存储
  • 传输加密：使用 HTTPS 和 WSS 加密协议传输数据
  • 访问控制：严格的数据访问权限控制，仅授权人员可以访问
  • 安全审计：定期进行安全审计和漏洞扫描
  • 匿名化处理：对部分数据进行去标识化或匿名化处理

4.2 管理措施

  • 建立数据安全管理制度
  • 对员工进行数据安全培训
  • 与第三方服务商签署保密协议
  • 建立安全事件应急预案

4.3 安全事件处置

如不幸发生个人信息安全事件，我们将按照法律法规的要求，及时向您告知：

  • 安全事件的基本情况和可能的影响
  • 我们已采取或将要采取的处置措施
  • 您可自主防范和降低风险的建议
  • 对您的补救措施

五、您如何管理您的个人信息

我们非常重视您对个人信息的关注，并尽全力保护您对于个人信息的访问、更正、删除以及撤回同意的权利。

5.1 访问和更正您的个人信息

您可以通过以下方式访问和更正您的个人信息：

  • 在"我的"页面查看和编辑个人资料
  • 在设置中管理账号信息
  • 查看和管理您的聊天记录
  • 查看和管理您发布的动态

5.2 删除您的个人信息

您可以通过以下方式删除您的部分个人信息：

  • 删除聊天记录
  • 删除发布的动态
  • 删除好友关系
  • 清除缓存数据

5.3 注销账号

您可以在应用中申请注销账号。账号注销后：

  • 我们将停止为您提供产品或服务
  • 我们将删除您的个人信息，或进行匿名化处理
  • 您将无法找回该账号下的任何内容或信息

账号注销是不可逆的操作，请您谨慎操作。

5.4 撤回同意

您可以通过以下方式撤回您的授权同意：

  • 在设备设置中关闭相应权限
  • 在应用设置中关闭相关功能

撤回同意不会影响此前基于您授权而开展的个人信息处理。

六、未成年人的个人信息保护

我们非常重视未成年人的个人信息保护：

  • 如果您是未成年人，请在监护人的陪同下阅读本政策，并在监护人同意的前提下使用我们的服务
  • 如果您是未成年人的监护人，请您关注未成年人是否在取得您的授权同意后使用我们的服务
  • 如果我们发现在未事先获得可证实的监护人同意的情况下收集了未成年人的个人信息，会设法尽快删除相关数据

特别提示：如果您未满18周岁，请您的监护人仔细阅读本隐私政策，并在征得您的监护人同意的前提下使用我们的服务或向我们提供信息。

七、隐私政策的更新

我们可能会适时对本隐私政策进行修订。当隐私政策发生变更时：

  • 我们会在应用内通过弹窗、推送通知等形式向您展示变更后的隐私政策
  • 如果变更会导致您在本政策下权利的实质减少，我们将在变更生效前通过显著方式提示您
  • 如果您不同意修改后的隐私政策，您有权并应立即停止使用我们的服务
  • 如果您继续使用我们的服务，即表示您同意受修订后的隐私政策的约束
