隐私协议

更新日期：2025年11月14日

我们重视并保护用户的隐私信息。本隐私协议说明了我们如何收集、使用、存储和保护您的个人信息。

1. 信息收集

我们会收集您在使用服务时提供的信息，包括但不限于：

  • 账号信息（用户名、密码）
  • 个人信息（姓名、手机号、邮箱等）
  • 设备信息（设备型号、操作系统版本等）
  • 日志信息（IP地址、访问时间、访问页面等）

2. 信息使用

我们会使用收集的信息用于以下目的：

  • 提供、维护和改进我们的服务
  • 处理您的请求和查询
  • 发送服务相关的通知和更新
  • 保护账号安全，防止欺诈行为
  • 分析服务使用情况，优化用户体验

3. 信息保护

我们采取以下措施保护您的个人信息：

  • 使用加密技术传输和存储敏感信息
  • 限制员工访问个人信息的权限
  • 定期进行安全评估和更新
  • 遵守相关法律法规的要求

4. 信息共享

我们不会将您的个人信息出售给第三方。但在以下情况下，我们可能会共享您的信息：

  • 获得您的明确同意
  • 为提供服务所必需的第三方服务商
  • 遵守法律法规的要求
  • 保护我们或他人的合法权益

5. 您的权利

您对自己的个人信息享有以下权利：

  • 访问和查看您的个人信息
  • 更正不准确的个人信息
  • 删除您的个人信息
  • 撤回授权同意
  • 投诉和举报

6. 第三方SDK及权限说明

为了向您提供更好的服务体验，我们的应用集成了以下第三方SDK和系统权限：

6.1 网络通信类

• Dio网络框架
  - 用途：实现HTTP网络请求，用于登录、注册、数据传输等功能
  - 收集信息：网络状态、请求响应数据
  - 开发者：Flutter社区开源项目
  - 隐私政策：https://pub.dev/packages/dio
• WebSocket连接
  - 用途：实现即时通讯功能，保持消息实时同步
  - 收集信息：设备标识、用户ID、消息内容、连接状态
  - 数据传输：全程加密传输

6.2 多媒体处理类

• CachedNetworkImage图片缓存
  - 用途：优化图片加载速度，减少流量消耗
  - 收集信息：图片缓存数据、设备存储信息
  - 存储位置：应用沙盒目录
  - 隐私政策：https://pub.dev/packages/cached_network_image
• ImagePicker图片选择器
  - 用途：选择相册图片或拍照功能
  - 所需权限：相机权限、相册访问权限
  - 收集信息：仅访问用户主动选择的图片
  - 隐私政策：https://pub.dev/packages/image_picker
• ImageGallerySaver图片保存
  - 用途：将聊天图片保存到系统相册
  - 所需权限：相册写入权限
  - 收集信息：无，仅保存用户主动选择的图片
  - 隐私政策：https://pub.dev/packages/image_gallery_saver
• VideoPlayer视频播放器
  - 用途：播放视频消息
  - 收集信息：视频文件元数据（时长、分辨率等）
  - 隐私政策：https://pub.dev/packages/video_player
• FlutterTTS语音合成
  - 用途：文本朗读功能，将文字消息转为语音
  - 收集信息：待朗读的文本内容（不上传服务器）
  - 处理方式：本地设备处理，不涉及网络传输
  - 隐私政策：https://pub.dev/packages/flutter_tts

6.3 系统功能类

• PermissionHandler权限管理
  - 用途：统一管理应用权限申请
  - 所需权限：根据功能按需申请（相机、相册、存储等）
  - 权限使用：仅在用户主动使用相关功能时申请
  - 隐私政策：https://pub.dev/packages/permission_handler
• SharePlus分享功能
  - 用途：分享文字和图片到其他应用
  - 收集信息：仅访问用户主动选择的分享内容
  - 隐私政策：https://pub.dev/packages/share_plus
• PathProvider路径获取
  - 用途：获取应用临时目录和缓存目录
  - 收集信息：无，仅获取系统路径
  - 隐私政策：https://pub.dev/packages/path_provider
• SharedPreferences本地存储
  - 用途：存储应用配置、好友备注等本地数据
  - 存储位置：应用沙盒目录
  - 数据安全：仅应用本身可访问
  - 隐私政策：https://pub.dev/packages/shared_preferences

6.4 权限使用说明

我们会在使用以下权限前向您申请授权：

  • 相机权限：用于拍照发送图片或视频
  • 相册权限：用于选择相册中的图片或视频
  • 存储权限：用于保存图片到相册
  • 网络权限：用于消息收发和数据同步

您可以随时在系统设置中关闭这些权限，但可能会影响部分功能的使用。

6.5 数据安全承诺

  • 所有SDK均为开源社区广泛使用的成熟组件
  • 所有网络传输均采用HTTPS加密协议
  • 本地数据存储在应用沙盒内，其他应用无法访问
  • 我们不会收集您的通讯录、位置、剪贴板等敏感信息
  • 第三方SDK不会在后台自动收集或上传您的个人信息
